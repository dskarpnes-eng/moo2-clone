# MOO2 Core Loop (v0)

A browser-based, Master of Orion 2-inspired colonization/growth/research
loop. See `docs/superpowers/specs/2026-07-02-moo2-core-loop-design.md` for
the full design.

## Run

    npm start

Then open http://localhost:8000/index.html

## Test

    npm test

Requires Node 18 or later — the tests use the built-in `node:test` module, which isn't available in older Node versions.
